# SASRec 阅读笔记

- 原文：Wang-Cheng Kang、Julian McAuley，*Self-Attentive Sequential Recommendation*，ICDM 2018。[arXiv:1808.09781](https://arxiv.org/abs/1808.09781)；本地 [PDF](Kang_2018_SASRec.pdf)，10 页，v1。
- 核心问题：推荐下一件物品时，既要利用较长的历史，也要选择真正相关的近期行为。论文用自注意力处理这个平衡。
- 结构：按时间排列物品序列，加入位置表示，通过自注意力构造每个位置的历史状态，再预测下一物品。预测位置只能看到过去，不能看到未来。
- 建议重点读数据序列与训练样本的构造、因果 mask、负样本和排名评估协议，再看注意力可视化。模型结构之外，候选集合和历史排除规则同样影响离线指标。
- 与仓库关系：这是未来序列推荐的基线；当前没有序列数据或 Top-K 评估。实现时先固定时间切分和候选集合，再与简单序列/双塔基线比较。
- 自检：为什么需要因果 mask？目标物品是否能出现在输入历史中？采样候选与全量候选的 Recall@K 能否直接比较？
