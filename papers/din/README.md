# DIN 阅读笔记

- 原文：Guorui Zhou 等，*Deep Interest Network for Click-Through Rate Prediction*，KDD 2018。[arXiv:1706.06978](https://arxiv.org/abs/1706.06978)；本地 [PDF](Zhou_2018_Deep_Interest_Network.pdf)，9 页，v4。
- 核心问题：把用户历史压成一个固定向量，会让不同候选商品得到同一份兴趣表示，难以反映用户兴趣的多样性。
- 结构：对每个候选商品，用局部激活单元衡量历史行为与该候选的相关性，再汇聚出**随候选变化**的用户兴趣表示，供 CTR 预测使用。
- 建议先看固定长度历史汇聚为何受限，再看局部激活单元的输入、权重与输出；论文还讨论训练大规模网络的正则化与激活函数技术，可在理解主线后阅读。
- 与仓库关系：当前仓库没有用户行为序列。实现前要定义历史的时间边界、PAD mask，并防止当前目标事件进入历史；随后与平均池化历史基线比较。
- 自检：同一个用户面对两个候选商品时，DIN 的兴趣向量为什么不同？为什么目标事件泄漏会使这一实验失真？
