# 02 · Factorization Machine CTR 实验

## 问题与模型

LR 只能给输入特征分配一阶权重。这里保持原有的五列输入，**不提供**人工构造的 `sports_match = user_sports × item_sports`，检验 FM 能否通过可学习的二阶项捕捉交互。

模型输出 logits：

```text
z(x) = b + Σᵢ wᵢxᵢ + Σᵢ<ⱼ 〈vᵢ,vⱼ〉xᵢxⱼ
     = b + Σᵢ wᵢxᵢ + ½ Σ𝒇 [(Σᵢ vᵢ𝒇xᵢ)² − Σᵢ vᵢ𝒇²xᵢ²]
```

第二行将逐对计算的 `O(n²k)` 改为 `O(nk)`；`n` 是特征数，`k` 是隐向量维度。实现见 [model.py](model.py)，测试将高效计算与显式逐对求和比较到浮点精度，并检查交互向量收到梯度。这里是**五列稠密数值特征的原理实验**，还不是工业场景的稀疏 ID FM。

## 数据与训练协议

[`data.py`](data.py) 直接复用 LR 的数据生成器与 70%/15%/15% 切分，保留完全相同的标签和前五列特征。标准化统计量只来自训练集；生成器没有真实时间戳或时间漂移。三个 seed 分别生成不同样本，但每个 seed 内的三组模型面对相同的样本、标签和切分。

FM 使用 `BCEWithLogitsLoss`、Adam、最多 40 个 Epoch；每轮用验证 BCE 选择最佳参数，测试集在恢复最佳参数后评估。训练循环、历史和 checkpoint 见 [train.py](train.py)。FM 的优化器与 LR 的 SGD 不同，因此三组结果是**各自训练协议下的模型对照**，不能把全部差异归因于模型结构。

在 seed 42 上比较 `embedding_dim` 为 4、8、16 且学习率均为 0.01 的验证集最佳 BCE，依次为 0.281924、0.281623、0.281566。后续固定 `k=16`、学习率 0.01、40 Epoch、Batch Size 256，在 seed 7、42、2026 上报告结果。维度选择只依据验证 BCE；测试指标用于最终报告。LR 两组沿用各自原有默认训练配置。

## 复现命令

```bash
uv run pytest -q

for seed in 7 42 2026; do
  uv run python -m models.lr.train --seed "$seed"
  uv run python -m models.lr.train --seed "$seed" --include-cross
  uv run python -m models.fm.train --seed "$seed" --embedding-dim 16
done
```

每次运行创建新目录，旧结果不会被覆盖。FM 保存 `config.json`、`history.json`、`metrics.json` 和 `model.pt`。配置包含特征顺序、切分样本数、环境版本、Git commit 和 dirty 状态；checkpoint 保存最佳参数及标准化统计量。运行产物在 `outputs/`，未提交到 Git；下表给出这次的本地路径。

## 三个 seed 的结果

测试集指标如下；`AP` 是 Average Precision，代码字段名仍为 `pr_auc`。LogLoss 越低越好，AUC/AP 越高越好。每个 seed 的测试集有 3,000 条，实际 CTR 分别为 10.13%、10.37%、9.20%。

| 模型 | seed | AUC | AP | LogLoss | ECE | 最佳轮 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| LR | 7 | 0.746131 | 0.298938 | 0.288352 | 0.008085 | 40 |
| LR | 42 | 0.738985 | 0.342444 | 0.291989 | 0.014614 | 39 |
| LR | 2026 | 0.751389 | 0.251494 | 0.272410 | 0.017728 | 19 |
| LR + 人工交叉 | 7 | 0.768507 | 0.307423 | 0.283401 | 0.008170 | 38 |
| LR + 人工交叉 | 42 | 0.757314 | 0.348976 | 0.285596 | 0.008108 | 40 |
| LR + 人工交叉 | 2026 | 0.764896 | 0.259837 | 0.269297 | 0.017135 | 20 |
| FM，k=16 | 7 | 0.766701 | 0.305972 | 0.283437 | 0.005926 | 23 |
| FM，k=16 | 42 | 0.759272 | 0.352325 | 0.285336 | 0.007810 | 35 |
| FM，k=16 | 2026 | 0.763785 | 0.257384 | 0.269403 | 0.012124 | 30 |

下表是三个 seed 的**均值 ± 样本标准差**，仅描述这三次运行，不是置信区间。

| 模型 | AUC | AP | LogLoss | ECE |
| --- | ---: | ---: | ---: | ---: |
| LR | 0.745502 ± 0.006225 | 0.297625 ± 0.045489 | 0.284250 ± 0.010414 | 0.013476 ± 0.004921 |
| LR + 人工交叉 | 0.763572 ± 0.005713 | 0.305412 ± 0.044604 | 0.279431 ± 0.008845 | 0.011138 ± 0.005194 |
| FM，k=16 | 0.763253 ± 0.003743 | 0.305227 ± 0.047475 | 0.279392 ± 0.008702 | 0.008620 ± 0.003178 |

FM 相比基础 LR 的平均 AUC 提高约 0.01775，平均 LogLoss 降低约 0.00486。FM 与人工交叉 LR 的平均 AUC 相差约 -0.00032，平均 LogLoss 相差约 -0.00004，三次运行无法支持谁稳定更好的结论。FM 的 `user_sports` 与 `item_sports` 两个隐向量点积在三个 seed 上分别为正的 0.335、0.360、0.319，说明它确实学到与模拟生成规律一致的正向交互；其他特征对也会被 FM 建模，不能仅凭这一项断言全部收益来源。

FM 有 `5 × 16 + 5 + 1 = 86` 个参数；基础 LR 只有 6 个，人工交叉 LR 有 7 个。FM 三次训练（含每轮验证）的本机计时约 1.2–2.7 秒；LR 脚本目前没有相同口径的内部计时，因此不做速度优劣比较。这个小数据实验也不能证明 FM 在真实稀疏 CTR 数据上的泛化或线上价值。
